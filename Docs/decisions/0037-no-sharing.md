# 0037 不做分享与复制

状态：已定 · 2026-10-26 · 复制部分被 [0053](0053-copy-support.md) 取代（2026-10-29），分享与导出仍不做

## 决定

**不开发分享与复制功能。**

不做的事：

- 不统一文本可选中（标题、列表、表格保持不可选）
- 不做"分享选中文本"（系统分享面板）
- 不做导出（纯文本 / Markdown / PDF）

## 理由

这是阅读器，核心是"看得清、找得到、跳得过去"。分享与导出是另一类产品（笔记、协作）的能力，做进来会引出剪贴板格式、导出样式、分享目标适配等一串决定，与 AGENTS.md 里"不扩大范围"的约定相悖。

## 现状说明

正文段落用的是 `UITextView`，**默认仍可选中**——这是渲染方式的副作用，不是产品功能。如果希望彻底关掉（长按不再出现选择手柄），把 `isSelectable` 改成 `false` 即可，一行改动。

标题、列表、表格用 SwiftUI `Text`，本来就不可选。所以现状是"部分可选"，不做统一。

## 重审条件

若用户明确要求"把规则发到群里"（这是跑团场景里唯一高频的分享需求），再单独评估。

## 补记 · 2026-10-29：复制放开

用户明确要求内容可复制（DM 备团），重审条件触发。正文与速查页的选中复制已启用，见 [0053](0053-copy-support.md)。
本文"不开发分享与复制"里的复制部分不再有效；系统分享面板与导出仍然不做。
