# 0048 解析页面内联 CSS 的标题规则

状态：已定 · 2026-10-26

## 背景

此前只手工搬了共享样式表（`style.css`、`stat-block.css`）里的规则。而 **5,571 个页面自带内联 `<style>`**，其中大量是对标题的覆盖：

| 覆盖 | 页数 |
|---|---|
| `h1 { font-size: 22pt }` 这类字号 | 233 |
| `h1 { color: #971869 }`（紫）| 46 |
| `h1 { color: #ffffff }`（白）| 61 |
| `div.stat-block h5` | 300 |

这些页面的标题在源页和我们的渲染里颜色不同。

## 先纠正一个误判

最初以为 `col-2`、`ve-text-center`、`rd__h` 这些高频 class 有内联样式定义。实测：**整个仓库没有任何地方定义它们**——它们是 5etools 导出残留，没有对应样式。所以"按 class 解析 CSS"的价值不在这些 class，而在标签级规则。

## 决定

1. 构建期解析每页内联 `<style>`，只取**标签级**选择器（`h1`–`h6`）的 `color` 与 `font-weight`。
2. 结果写到标题块的 `style` 字段（`{"c": "#ff8000", "b": 1}`），随内容进库。
3. 渲染时：块上的颜色优先于全局规则（[0017](0017-dark-mode.md) 的 `SourceStyle`），并同样走对比度修复。
4. **不解析**字号、边距、盒模型——排版尺度仍由我们统一决定，否则每页都会变成另一套版式。

## 覆盖

1,329 个标题块、239 个页面拿到了页级颜色/字重。最常见的覆盖色：`#704cd9`（483）、`#002d43`（107）、`#0000ff`（69）、`#ff8000`（52）。

## 顺带修掉：布局表格

第三方书里常见 `<TABLE style="WIDTH: 1200px"><tr><td>…整页内容…</td></tr></TABLE>`——这是排版容器，不是数据表。之前按数据表渲染，整页被压成一条窄栏。

现在单行单列的表格直接铺开内容，不画边框、不按列宽压缩。

## 重审条件

- 若发现颜色以外的属性（字号、行高）在页面间差异大到影响阅读，再扩白名单。
- 若布局表格出现"多行单列"的形态，再扩展判定条件。
