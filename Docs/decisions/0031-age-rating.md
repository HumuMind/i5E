# 0031 年龄分级：13+

状态：已定 · 2026-10-21 · 上架地区待定

## 分级档位说明

Apple 从 2025 年起把分级从 4+/9+/12+/17+ 换成了 **4+ / 9+ / 13+ / 16+ / 18+**。
口语里的"12+"在新体系里对应 **13+**。

## 内容抽查（全库约 1,108 万字）

| 关键词 | 出现次数 | 说明 |
|---|---|---|
| 血 | 5,766 | 战斗伤害、怪物描述 |
| 尸 | 2,434 | 亡灵、尸体相关 |
| 恐怖 | 1,418 | 鸦阁魔域等恐怖主题 |
| 酒 | 1,461 | 酒馆、饮酒场景 |
| 性 | 18,185 | **绝大多数是"属性/特性"**，非性内容 |
| 裸 | 45 | 少量 |
| 赌 | 358 | 规则里的掷骰/卡牌，非赌博机制 |

## 拟填写的问卷答案

| 项目 | 拟填 | 依据 |
|---|---|---|
| 卡通或奇幻暴力 | 轻微/偶发 | 文字描述的伤害与战斗，无画面 |
| 写实暴力 / 血腥细节 | 无 | 上限是"血""尸"这类词 |
| 粗俗语言 | 无 | 未发现 |
| 成人/暗示主题 | 轻微/偶发 | 少量（"裸"45 处）|
| 恐怖/惊悚主题 | 轻微/偶发 | 鸦阁魔域一整条产品线 |
| 酒精、烟草、毒品 | 轻微/偶发 | 酒馆与饮酒描写 |
| 模拟赌博 | 无 | 掷骰是游戏规则，不涉及下注 |
| 无限制网页访问 | 无 | **完全离线**，这是分级上的一个优势 |
| 用户生成内容 | 无 | 无账号、无 UGC |

按这组答案，结果是 **13+**。

## 注意

这是抽样判断，不是逐页审查。提交前若审核方提出异议，按他们的要求上调即可——分级不是产品质量问题，虚报才是。
