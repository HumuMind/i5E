# 0046 按 class 还原源页样式

状态：已定 · 2026-10-26

## 问题

对比源页渲染后发现，怪物数据块这类页面我们和源页差得很远：没有边框容器、怪物名和正文一样大、属性表挤成一团、AC/HP 表带着空列。

根因不是"某页排版不好"，而是**源页用 class 表达的结构性样式，我们一层都没搬**。之前只搬了标签规则（h1–h6、U/EM 组合），class 规则（`stat-block.css`）被忽略了。

## 决定

按 class 还原**结构性**样式，不做逐页修补。覆盖范围：

| class | 样式 | 页面数 |
|---|---|---|
| `div.stat-block` | 底色 `#f8f8f6`、3px 双线边框、内边距 15、最大宽 560 | 896 |
| `div.little-paper` | 底色 `#faf0eb`、双线边框 `#9e6859` | — |
| `div.HT` | 底色 `#f0e9da`、仅上边框 | — |
| `stat-block` 内的 h5/h6 | 暗红加粗 + 下划线 | 896 |
| `div.sub-line` | 灰色斜体 | 743 |
| `td.c1`–`c4` | 属性表斑马纹 | 761 |
| `table.basic/center/part` | 无边框 | — |

值全部来自 `DND5e_chm/stat-block.css`，集中在 `ContentKit.ClassStyle` 里。

## 顺带修掉的两个通用问题

**1. 空列折叠。** 源页用 `<td width=40%>` 占位、用 `<td WIDTH=5px>` 做间隔，这些列没有文字却被算进列宽。`TableLayoutCalculator.normalize` 展开 colspan → 去掉整列为空的列 → 重新合并，属性表从 14 列降到 12 列，AC 表不再有空白列。

**2. 容器内宽下传。** 容器有最大宽度，子块却按整页宽度排版，表格会撑出边框被裁掉。现在容器把自己的内宽传给子块。

## 效果

怪物页从"表格散架"变成与源页基本一致：带边框的卡片、暗红标题、斑马纹属性表、无边框数据表。

## 没做的

- 不解析 CSS 文件本身（不做通用 CSS 引擎），只映射已知的结构性 class。
- 不还原排版微调（字号百分比、margin 微调），那些由我们的排版系统统一决定。
- `table.stat-abilities` 的居中与 `nowrap` 未还原——我们的表格统一左对齐，避免中文换行时的错位。

## 重审条件

若发现大量页面用了未被收录的 class（比如第三方书自带的样式表），再扩充映射表。
