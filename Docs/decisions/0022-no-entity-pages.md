# 0022 不做实体索引页

状态：已定 · 2026-10-21

## 背景

[0001](0001-content-model.md) 计划在文档流之上做实体标注，第一批是法术，并预留了"实体索引页"（按环阶/学派筛选的独立页面）。I13 做完速查页之后，这个计划的必要性需要重新评估。

## 事实

`速查/法术速查/5E万法大全.html` 本身就是跨书聚合的：

| 来源 | 条数 |
|---|---|
| PHB24 | 391 |
| PHB14 | 361 |
| XGE（珊娜萨）| 95 |
| AU | 33 |
| TCE（塔莎）| 21 |
| FR | 19 |
| EGW | 15 |
| FTD（费资本）| 7 |
| 其余 9 种 | 33 |
| **合计** | **969 条 / 17 个来源** |

而 [0020](0020-reference-pages.md) 已经把这类页面做成了卡片瀑布流 + 分面筛选（环阶 / 学派 / 来源）。

## 决定

**不做实体索引页。**

三条现有能力已经覆盖：

1. **按条件找**：速查页的卡片 + 分面筛选。
2. **按名字找**：全文搜索。
3. **从正文跳**：交叉引用。

实体页唯一可能的增量是「法术 + 怪物 + 物品混在一个索引里」，但那不是真实使用场景——没人会把火球术和巨剑放在一起筛。

## 代价

- 构建期抽取的 1,290 条法术**暂时没有 UI 消费方**。它仍然有用：结构规整、可验证、将来若要做"法术对比""版本差异"这类功能是现成数据。但不要为了"数据已经抽好了"而硬造一个界面。
- 跨版本重名（359 个法术两版同 id）的实体主键问题**因此不必解决**——不做索引页就没有主键。

## 重审条件

出现以下任一情况再回来：

- 需要在**不同实体类型之间**做联合检索（比如"某 CR 的怪物掉落了哪些魔法物品"）。
- 需要跨书做**对比式**展示（2014 与 2024 同一法术的并排差异）。
- 速查表本身缺失（上游不再生成），只能用正文重建索引。
