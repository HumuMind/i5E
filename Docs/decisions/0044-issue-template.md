# 0044 Issue 模板

状态：已定 · 2026-10-26（仓库尚未公开，模板先备好）

## 决定

`.github/ISSUE_TEMPLATE/bug.yml` 一个表单模板，包含：

| 字段 | 为什么需要 |
|---|---|
| 问题类型 | 先把"应用问题"和"内容问题"分开——后者应转给上游 |
| 复现步骤 | 没有步骤的问题基本无法处理 |
| 期望结果 | 区分"坏了"和"就是这样设计的" |
| 版本信息 | 设置页可直接抄，见 [0039](0039-content-version.md) |
| 设备与系统 | iPad / iPhone / Mac 行为差异很大 |

## 为什么只有一个模板

功能建议与问题反馈在这个阶段没有区别——都是"我们希望它变成什么样"。多个模板只会让填写者犹豫选哪个。

等真有人提 PR 时再加 `pull_request_template.md`，那时才有可检查的清单。

## 现状

仓库还没有远程地址（[0034](0034-testflight.md)），模板暂时不会出现在任何地方。先提交进仓库，公开时自动生效。
