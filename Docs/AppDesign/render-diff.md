# 渲染差异清单

对比源仓库（浏览器渲染）与 App 的差异记录。**已定过的不再重复讨论**，新发现追加到表尾。

判定口径：
- **已改**：App 已按源页行为实现，附对应决策
- **不改**：看过并决定维持现状，附理由
- **待定**：已记录，等待决定

## 已定

|---|---|---|---|---|

| 2 | 行距 1.8 比源页 1.4 松散，一屏内容少一半 | 全局 | **不改**：手机上的点击目标优先 | [0011](decisions/0011-typography.md) 补记 |

## 本轮新增结论

- `caption` 里的换行也在本轮修掉了（源页 `<caption>` 内有换行，之前被当硬换行渲染成三行）
- 表格 class 含 `w-100` 时按比例铺满可用宽度（源页要求 100%）
